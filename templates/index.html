API de Empresa Comercial

Documentación de la API RESTful para el sistema de gestión de la empresa comercial.

GET /api/categorias

Obtiene todas las categorías disponibles en el sistema.

Ejemplo:
/api/categorias

GET /api/productos

Obtiene productos filtrados según categoría o términos de búsqueda.

Parámetros opcionales:

  • categoria - ID de la categoría
  • busqueda - Término de búsqueda
Ejemplo:
/api/productos?categoria=1&busqueda=laptop

GET /api/productos/{id}

Obtiene detalles de un producto específico, incluyendo sus reseñas.

Parámetros:

  • id - ID del producto (en la URL)
Ejemplo:
/api/productos/5

GET /api/resenas

Obtiene las 4 reseñas más destacadas (ordenadas por estrellas).

Ejemplo:
/api/resenas

POST /api/login

Estructura de la Base de Datos

Tabla: categoria

Campo Tipo Descripción
id INT Identificador único de la categoría
nombre VARCHAR(100) Nombre de la categoría
descripcion TEXT Descripción detallada de la categoría

Tabla: productos

Campo Tipo Descripción
id INT Identificador único del producto
Nombre VARCHAR(100) Nombre del producto
Descripcion TEXT Descripción detallada del producto
Precio DECIMAL(10,2) Precio del producto
Stock INT Cantidad disponible en stock
id_categoria INT Categoría a la que pertenece el producto
imagen VARCHAR(255) URL o ruta de la imagen del producto

Tabla: usuario

Campo Tipo Descripción
id INT Identificador único del usuario
Nombre VARCHAR(100) Nombre del usuario
Ciudad VARCHAR(100) Ciudad de residencia del usuario

Tabla: reseña

Campo Tipo Descripción
id INT Identificador único de la reseña
id_usuario INT ID del usuario que hizo la reseña
id_Producto INT ID del producto reseñado
Contenido VARCHAR(200) Título o resumen de la reseña
Reseña TEXT Texto completo de la reseña
Fecha DATE Fecha de publicación de la reseña
Hora TIME Hora de publicación de la reseña
Estrellita INT Calificación de 1 a 5 estrellas
